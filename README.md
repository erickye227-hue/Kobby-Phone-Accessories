# Kobby's Phone Accessories & Repair

An online phone accessories store website built with HTML, CSS, and JavaScript.

## Project Description

Kobby's Phone Accessories & Repair is an e-commerce website that allows customers to view products, add items to a cart, checkout, and place orders. It also includes an admin dashboard for managing products and customer orders.

## Completed Features

✅ Product display system  
✅ Shopping cart  
✅ Increase and decrease product quantity

✅ Admin dashboard

## Current Limitation

The website currently uses browser LocalStorage to store products and orders. This means data is saved separately on each device.
